# Finance App

财务应用模块 - React 版本

## 迁移说明

此应用从 `products/pc-admin/apps/finance-app` 迁移到 `products/react-admin/apps/finance-app`。

### 主要变更

- Vue 3 -> React 18
- Vue Router -> React Router DOM
- Element Plus -> Ant Design
- Pinia -> React Hooks / Zustand

## 启动方式

```bash
pnpm dev
```

## 构建

```bash
pnpm build
```
