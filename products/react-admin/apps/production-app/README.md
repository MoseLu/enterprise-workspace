# 生产应用 (Production App)

生产管理模块，从 Vue3 + Element Plus 迁移到 React + Ant Design。

## 技术栈

- React 18
- TypeScript 5
- Vite 5
- Ant Design 5
- React Router 6

## 开发

```bash
# 在 react-admin 根目录运行
pnpm dev:app --app production-app
# 或直接运行
cd apps/production-app && pnpm dev
```

## 构建

```bash
pnpm build:app --app production-app
# 或
cd apps/production-app && pnpm build
```
