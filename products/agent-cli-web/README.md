# Agent CLI Web

**状态**: 占位符项目（待开发）

## 项目意图

本项目旨在提供一个基于 Web 的 Agent 命令行界面工具，允许用户通过浏览器与 AI Agent 进行交互，类似于传统的 CLI 体验但在 Web 环境中实现。

## 预期功能

- Web 终端模拟器界面
- Agent 命令交互
- 会话管理与历史记录
- 命令自动补全与建议
- 多 Agent 实例管理
