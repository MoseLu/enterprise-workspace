# 企业工作空间 Git 仓库架构

> 本文档描述企业工作空间的 Git 仓库架构设计，采用「顶层根仓库 + Git Submodule」模式，实现全局工程化整合与子仓库独立迭代的平衡。

## 一、核心设计原则

1. **顶层根仓库 = 全局工程化整合基座**：仅存放跨所有模块的全局配置、脚本、CI/CD 模板、文档，不包含业务核心代码，是整个项目的唯一入口；
2. **子仓库 = 高模块**：每个子仓库聚焦单一技术内聚独立业务栈/业务领域，内部保持完整的工程化能力，可独立启动、独立迭代、独立发布；
3. **版本隔离 + 全局锁定**：子仓库采用语义化版本独立打 Tag，顶层根仓库通过 Git Submodule 仅锁定子仓库的稳定版本；
4. **多团队协作边界清晰**：每个子仓库对应专属开发团队，架构团队仅维护顶层根仓库和子仓库版本关联。

## 六、团队协作规范

### 分支策略

- **main**：生产分支
- **develop**：开发分支
- **feature/**：功能分支
- **bugfix/**：修复分支
- **hotfix/**：紧急修复分支

### 提交规范

遵循 Conventional Commits：

```
<type>(<scope>): <description>

# 示例：
feat(agent-orchestrator): 添加 Agent 调度功能
fix(pc-admin): 修复用户列表分页问题
docs: 更新 API 文档
```

### 子仓库操作流程

#### 子仓库独立开发

```bash
# 进入子仓库目录
cd products/agent-orchestrator

# 创建开发分支
git checkout -b feature/new-feature

# 开发并提交
git add .
git commit -m "feat: 添加新功能"

# 推送到远程
git push origin feature/new-feature
```

#### 更新顶层根仓库

```bash
cd enterprise-workspace

# 更新子仓库到指定版本
cd products/agent-orchestrator
git checkout v1.0.0

# 回到顶层根仓库，提交变更
cd ../..
git add products/agent-orchestrator
git commit -m "chore: 更新 agent-orchestrator 到 v1.0.0"
git push origin develop
```

## 七、CI/CD 配置

### GitHub Actions 工作流

| 工作流 | 触发条件 | 职责 |
|--------|----------|------|
| ci.yml | PR/提交到 main | 代码检查、测试、构建 |
| feature-branch.yml | PR 到 feature/* | 特性分支验证 |
| hotfix.yml | PR 到 hotfix/* | 紧急修复验证 |
| pr-validation.yml | 所有 PR | PR 预检 |

### 子仓库 CI/CD

每个产品子仓库配置独立的 CI/CD：

- **构建**：代码检查、类型检查、单元测试
- **部署**：独立部署到测试环境
- **发布**：语义化版本打 Tag

## 九、常见问题

### Q1：子仓库代码未同步？

```bash
# 更新所有子仓库
git submodule update --init --recursive

# 或更新特定子仓库
git submodule update --init products/agent-orchestrator
```

### Q2：如何为子仓库添加远程分支？

```bash
cd products/agent-orchestrator
git remote add origin https://github.com/BellisGit/agent-orchestrator-platform.git
git fetch origin
git checkout -b main origin/main
git push -u origin main
```

### Q3：如何更新子仓库到新版本？

```bash
cd products/agent-orchestrator
git fetch origin
git checkout v1.1.0

# 回到顶层根仓库
cd ../..
git add products/agent-orchestrator
git commit -m "chore: 更新 agent-orchestrator 到 v1.1.0"
```

### Q4：子仓库处于 detached 状态？

```bash
cd references/art-design-pro
git checkout develop
git branch --set-upstream-to=origin/develop develop
```
