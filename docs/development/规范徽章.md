# 规范符合性徽章

各子项目可在 README.md 中添加以下徽章，显示符合系统级规范。

```markdown

```

## 徽章示例

### 完整版（推荐）

```markdown

[![PR Validation](https://github.com/BellisGit/enterprise-workspace/actions/workflows/pr-validation.yml/badge.svg)](https://github.com/BellisGit/enterprise-workspace/actions)

项目描述...

## 开发规范

本项目遵循 [Enterprise Workspace 系统级开发规范](../../docs/规范/系统开发规范.md)。
```

## 徽章说明

| 徽章 | 说明 | 链接 |
|------|------|------|
| Branch Strategy | 分支策略符合性 | 规范文档 |
| CI Status | CI 流水线状态 | Actions 页面 |
| PR Validation | PR 验证状态 | Actions 页面 |

## 在各项目中添加

### 在 products/*/README.md 中添加

```markdown
---

## 规范符合性

[![Branch Strategy](https://img.shields.io/badge/branch-strategy-compliant-brightgreen)](../../docs/规范/系统开发规范.md)

本项目遵循 [Enterprise Workspace 系统级开发规范](../../docs/规范/系统开发规范.md)。
```

### 在 services/*/README.md 中添加

```markdown
---

## 规范符合性

[![Branch Strategy](https://img.shields.io/badge/branch-strategy-compliant-brightgreen)](../../docs/规范/系统开发规范.md)

本服务遵循 [Enterprise Workspace 系统级开发规范](../../docs/规范/系统开发规范.md)。
```

## 合规检查清单

各项目应定期检查以下项目：

- [ ] 遵循分支命名规范
- [ ] 遵循提交消息格式
- [ ] 通过 CI 流水线检查
- [ ] PR 经过审批后合并
- [ ] 文档已更新
